# Центр перепродажи: LIS-SKINS → Steam + FunPay

Один центр, который запускает и объединяет двух торговых ботов:

| Бот | Что делает | Где код |
|---|---|---|
| **LisBot** (Node.js) | Закупает предметы CS2 на LIS-SKINS по низу рынка (скан + мгновенная покупка новых лотов, RTBA), принимает трейды и после Trade Protection продаёт на Торговой площадке Steam | `bots/lisbot` |
| **MannBot** (Python) | Продаёт ключи Mann Co. на FunPay: ведёт сделку в чате заказа, отправляет трейд-оффер, держит цену конкурентов (RTBA), антифрод, CRM заказов | `bots/mannbot` |
| **Центр** (Python) | Запускает обоих ботов, следит за ними и перезапускает при сбоях, показывает общую панель: состояние, ключевые цифры, тревоги, журналы, управление | `center/` |

## Как устроено

```
                 ┌──────────────── Центр (python -m center), панель :8800 ───────────────┐
                 │  воркеры: запуск, проверка здоровья, перезапуск с паузой, журналы     │
                 │  сводка и тревоги обоих ботов · журнал событий center.sqlite3          │
                 └───────┬─────────────────────────────────────────────────────┬─────────┘
          процесс node   │  HTTP API + чтение базы                 процесс python │  HTTP API + чтение базы
                 ┌───────▼────────┐                                   ┌────────▼────────┐
                 │ LisBot  :8802  │  своя панель, своя база            │ MannBot  :8801  │
                 │ src/index.js   │  center-data/lisbot/data           │ app.launcher    │
                 └────────────────┘                                   └─────────────────┘
```

* Каждый бот работает отдельным процессом, как и раньше, со своей панелью и базой. Торговая логика ботов не переписывалась: центр общается с ними через их собственные веб-API и читает их базы только на чтение.
* Если бот упал, центр перезапускает его с растущей паузой (2 с → 5 мин). Если бот падает сразу после запуска 5 раз подряд, перезапуски прекращаются и в журнал центра пишется критическое событие.
* Если LisBot сообщает, что не заполнены настройки, центр показывает «нужна настройка» со списком того, чего не хватает, и не перезапускает его впустую.
* Кнопка «Открыть панель бота» открывает полную панель LisBot или MannBot уже со входом.

## Запуск

Нужны **Python 3.11+** и **Node.js 20+** (Node нужен только LisBot).

* **Windows:** запустите `Center.bat`. Он сам поставит Python-пакеты и зависимости LisBot, затем откроет панель в браузере.
* **Linux / macOS / VPS:** `./center.sh` (на сервере: `./center.sh --no-browser --host 0.0.0.0`).
* Вручную: `pip install -r requirements.txt`, `cd bots/lisbot && npm ci --omit=dev`, затем `python -m center`.

Посмотреть без аккаунтов: `python -m center --demo`. MannBot запустится с эмуляцией FunPay и Steam и демо-заказами, LisBot будет ждать настройки.

### Первая настройка

1. **LisBot:** в карточке LisBot нажмите «Подключения» и введите ключ API LIS-SKINS, логин и пароль Steam, `shared_secret` и `identity_secret` из maFile, трейд-ссылку и, по желанию, Telegram. Параметры стратегии меняются во вкладке «Настройки» панели LisBot.
2. **MannBot:** «Открыть панель бота» → мастер настройки (golden_key FunPay, maFile Steam, Telegram).
3. Оба бота стартуют в **тестовом режиме** и ничего не покупают и не продают. Боевой режим включается в панели каждого бота.

### Где лежат данные

Всё хранится в `center-data/` рядом с программой (или в папке из `--home` / `$CENTER_HOME`):

```
center-data/
  center.yaml        порт панели, токен входа, какие боты запускать, параметры перезапуска
  center.sqlite3     журнал событий центра, история состояния ботов, уведомления
  logs/              вывод центра и каждого бота
  lisbot/            secrets.env (ключи), config.json (стратегия), data/ (база и логи LisBot)
  mannbot/           config.yaml и data/ MannBot
```

Чтобы перенести центр на другой компьютер или сделать резервную копию, достаточно скопировать эту папку. В `center.yaml` можно выключить бота (`workers.lisbot.enabled: false`), отключить автозапуск или поменять порты.

### Мониторинг

Раздел «Мониторинг» панели центра показывает аптайм и время ответа каждого бота за 24 часа, 7 или 30 дней, а также все уведомления центра.

* **Уведомления в Telegram:** падение или перезапуск бота, «бот не отвечает» (несколько проверок подряд), критические тревоги ботов, аварийное выключение центра в прошлый раз. Одинаковые уведомления не повторяются чаще раза в 15 минут, в тихие часы некритичное копится и приходит одним сообщением. Токен и chat id задаются кнопкой «Настройки уведомлений»; если их нет, центр берёт Telegram из подключений LisBot.
* **Сторожевой пинг:** укажите URL проверки с healthchecks.io (или похожего сервиса). Центр пингует его раз в минуту; если пинги пропали, значит выключился сам центр или компьютер, и сервис сообщит об этом.
* **Ежедневный отчёт** в заданное время: аптайм, перезапуски, тревоги и показатели обоих ботов за сутки. Кнопка «Отчёт за сутки» показывает его сразу.
* Тревоги ботов подтверждаются прямо в центре (кнопка ✓ или «Подтвердить все»), подтверждение уходит в самого бота.

Все параметры лежат в разделе `monitor` файла `center.yaml`.

## Боты по отдельности

Каждого бота по-прежнему можно запускать и собирать отдельно, как в исходных проектах:

* LisBot: `bots/lisbot/README.md` (десктоп-приложение Electron с установщиком: `npm run build:win`).
* MannBot: `bots/mannbot/README.md` (портативная Windows-версия, Docker; сборка exe в GitHub Actions — workflow «Build MannBot»).

## Проверки

```
python -m pytest -q                        # центр
cd bots/mannbot && python -m pytest -q     # MannBot (30 тестов)
cd bots/lisbot && npm test                 # LisBot (26 тестов)
```

Все три набора запускаются в GitHub Actions на каждый пуш.

**Что не проверено:** работа ботов на настоящих LIS-SKINS, Steam и FunPay. Из среды разработки эти сайты недоступны, поэтому боты по умолчанию в тестовом режиме. Центр и оба бота проверены на Linux; на Windows центр ещё не запускался.
