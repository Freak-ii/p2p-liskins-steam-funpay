# Windows 10/11-версия Центра

Установщик `StarsCenter-<версия>-setup.exe` и портативный архив `StarsCenter-<версия>-win64-portable.zip`
со всеми ботами Центра (StarsBot, MannBot, LisBot). Python и Node.js у пользователя ставить не нужно:
они уже внутри.

## Как получить

* **GitHub Actions:** вкладка Actions → **Build Windows** → Run workflow. Готовые файлы лежат в артефакте
  `StarsCenter-windows-<версия>`. Пуш тега `center-v1.2.3` собирает версию 1.2.3.
* **Локально на Windows:** нужен Python 3.11+ и [Inno Setup 6](https://jrsoftware.org/isdl.php):
  ```
  python packaging\windows\build.py --lisbot --installer
  ```
  Без `--lisbot` LisBot и Node.js в сборку не попадут (так можно собирать и на Linux, но только zip).

## Что делает установщик

* Ставит программу в `%LOCALAPPDATA%\Programs\StarsCenter`, права администратора не нужны.
* Ярлыки «Центр», «Центр (с окном журнала)», «Центр — демо без аккаунтов», «Папка данных».
* По желанию: ярлык на рабочем столе и автозапуск при входе в Windows (без открытия браузера).
* Данные (настройки, ключи, базы, журналы) лежат отдельно, в `%LOCALAPPDATA%\StarsCenter\center-data`,
  и переживают обновление и удаление программы. Обновление = запустить новый установщик поверх старого:
  он сам остановит запущенный центр.

## Как устроено

| Файл | Зачем |
|---|---|
| `build.py` | собирает папку `dist/windows/StarsCenter`: официальный CPython 3.12 из nuget, колёса win_amd64 для всех `requirements.txt` (корень и `bots/*/`), код `center/` и `bots/` без тестов, Node.js и `node_modules` LisBot, иконку |
| `launch.pyw` | точка входа: данные в `%LOCALAPPDATA%`, Node.js из сборки в PATH, ботов запускает через `python.exe` без окон; если LisBot не собран — выключает его в `center.yaml` |
| `StarsCenter.iss` | установщик Inno Setup |
| `smoke_test.py` | проверка сборки: демо-режим, все Python-боты в состоянии running, корректный выход |

Почему не PyInstaller: центр запускает каждого бота отдельным процессом `python -m <бот>`, ему нужен
настоящий интерпретатор. Встроенный официальный CPython работает без изменений кода ботов, а новый
Python-бот попадает в сборку сам, как только его зависимости есть в `requirements.txt`.

## Что важно на Windows 11

* **SmartScreen.** Сборка не подписана сертификатом, поэтому при первом запуске будет «Windows защитила ваш
  компьютер» → «Подробнее» → «Выполнить в любом случае».
* **Сон и питание.** Пока бот продаёт, ПК не должен засыпать: Параметры → Система → Питание и батарея →
  «Переводить в спящий режим» = «Никогда». Для круглосуточной работы надёжнее VPS (Linux: `./center.sh`).
* **Брандмауэр.** Панели слушают только `127.0.0.1`, запрос брандмауэра появляться не должен.
* **Антивирус.** Если Defender поместил файл в карантин, добавьте папку программы в исключения.
