# Windows 10/11-версия Центра

Установщик `StarsCenter-<версия>-setup.exe` и портативный архив `StarsCenter-<версия>-win64-portable.zip`
со всеми ботами Центра (StarsBot, MannBot, LisBot). Python и Node.js у пользователя ставить не нужно:
они уже внутри.

## Как получить

* **GitHub Actions:** вкладка Actions → **Build Windows** → Run workflow. Готовые файлы лежат в артефакте
  `StarsCenter-windows-<версия>`. Пуш тега `center-v1.2.3` собирает версию 1.2.3.
* **Локально на Windows:** нужен Python 3.11+ и [Inno Setup 6](https://jrsoftware.org/isdl.php):
  ```
  python packaging\windows\build.py --lisbot --installer
  ```
  Без `--lisbot` LisBot и Node.js в сборку не попадут.
* **На Linux без GitHub Actions** (так собрана версия 1.0.0): нужны `npm`, Wine с 32-битной частью
  (`wine64 wine32:i386`) и Inno Setup из nuget-пакета `Tools.InnoSetup` (ISCC.exe):
  ```
  LANG=C.UTF-8 python3 packaging/windows/build.py --lisbot --installer --iscc "wine /путь/ISCC.exe"
  ```
  better-sqlite3 у LisBot уже содержит готовую сборку под Windows, поэтому `node_modules` можно ставить на Linux.
  Под тем же Wine можно проверить результат: `wine runtime/python.exe app/launch.pyw --console --demo`.

## Как выглядит для пользователя

* **Первый запуск** сразу открывает мастер настройки StarsBot: golden_key FunPay, кошелёк TON, Fragment.
  Дальше ярлык «Центр» открывает общую панель.
* **Значок в трее** (рядом с часами): клик открывает панель. В меню есть пункты «Открыть StarsBot / MannBot / LisBot»,
  «Папка данных», «Журналы», «Запускать при входе в Windows», «Проверить обновления» и «Выключить центр и ботов».
  Закрытие вкладки браузера программу не останавливает, она продолжает работать в трее.
* **Повторный запуск** ярлыка при работающем центре просто открывает панель, вторая копия не стартует.

## Автообновление

Обновления берутся из GitHub Releases этого репозитория. Чтобы выпустить версию, запушьте тег `center-v1.2.3`:
workflow соберёт установщик и опубликует релиз с `SHA256SUMS.txt`. Программа проверяет релизы при запуске и раз в
сутки. Если есть новая версия, она показывает уведомление, а по клику скачивает установщик, сверяет SHA-256,
останавливает центр, тихо ставит новую версию и снова запускает её. Данные при этом не трогаются.

Репозиторий приватный, поэтому для проверки нужен токен GitHub **только на чтение**: fine-grained token
на этот репозиторий с правом *Contents: Read-only*. Его нужно записать в `%LOCALAPPDATA%\StarsCenter\updates.json`:

```json
{"repo": "Freak-ii/p2p-liskins-steam-funpay", "token": "github_pat_..."}
```

Без токена обновления не проверяются, пункт «Проверить обновления» сам создаст этот файл-заготовку.

## Что делает установщик

* Ставит программу в `%LOCALAPPDATA%\Programs\StarsCenter`, права администратора не нужны.
* Ярлыки «Центр», «Центр (с окном журнала)», «Центр — демо без аккаунтов», «Папка данных».
* По желанию: ярлык на рабочем столе и автозапуск при входе в Windows (без открытия браузера; тот же
  переключатель есть в меню трея).
* Данные (настройки, ключи, базы, журналы) лежат отдельно, в `%LOCALAPPDATA%\StarsCenter\center-data`,
  и переживают обновление и удаление программы. Обновление = запустить новый установщик поверх старого:
  он сам остановит запущенный центр.

## Как устроено

| Файл | Зачем |
|---|---|
| `build.py` | собирает папку `dist/windows/StarsCenter`: официальный CPython 3.12 из nuget, колёса win_amd64 для всех `requirements.txt` (корень и `bots/*/`), код `center/` и `bots/` без тестов, Node.js и `node_modules` LisBot, иконку |
| `launch.pyw` | точка входа: данные в `%LOCALAPPDATA%`, Node.js из сборки в PATH, ботов запускает через `python.exe` без окон |
| `desktop/app.py` | оболочка: центр в фоновом потоке, первый запуск, трей, проверка обновлений; если LisBot не собран — выключает его в `center.yaml` |
| `desktop/tray.py` | значок в трее на чистом ctypes (Win32 `Shell_NotifyIcon`), без лишних зависимостей |
| `desktop/updater.py`, `desktop/autostart.py` | обновления из GitHub Releases с проверкой SHA-256; автозапуск через `HKCU\…\Run` |
| `StarsCenter.iss` | установщик Inno Setup |
| `smoke_test.py` | проверка сборки: демо-режим, все Python-боты в состоянии running, корректный выход |

Почему не PyInstaller: центр запускает каждого бота отдельным процессом `python -m <бот>`, ему нужен
настоящий интерпретатор. Встроенный официальный CPython работает без изменений кода ботов, а новый
Python-бот попадает в сборку сам, как только его зависимости есть в `requirements.txt`.

## Что важно на Windows 11

* **SmartScreen.** Сборка не подписана сертификатом, поэтому при первом запуске будет «Windows защитила ваш
  компьютер» → «Подробнее» → «Выполнить в любом случае».
* **Сон и питание.** Пока бот продаёт, ПК не должен засыпать: Параметры → Система → Питание и батарея →
  «Переводить в спящий режим» = «Никогда». Для круглосуточной работы надёжнее VPS (Linux: `./center.sh`).
* **Брандмауэр.** Панели слушают только `127.0.0.1`, запрос брандмауэра появляться не должен.
* **Антивирус.** Если Defender поместил файл в карантин, добавьте папку программы в исключения.
