Шаг 1 · FunPay

Откройте funpay.com в браузере (вы должны быть залогинены) → F12 → Application (Приложение) → Cookies → https://funpay.com → строка golden_key → скопируйте Value. Никому его не показывайте.
ID лота — число из ссылки на ваш лот: funpay.com/lots/offer?id=12345. Подкатегория TF2 «Предметы» = 1808, игра = 435.
