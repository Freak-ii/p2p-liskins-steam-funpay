Шаг 1 · FunPay

funpay.com (вы залогинены) → F12 → Application → Cookies → https://funpay.com → golden_key → Value. Если на этом же аккаунте работает MannBot — это нормально: боты делят чаты и запросы через общий координатор.
ID лота — число из ссылки funpay.com/lots/offer?id=12345. Раздел Telegram → Звёзды, способ «По username». Пустое поле — номинал не продаётся.

Шаг 2 · Кошелёк TON бота

Отдельный кошелёк только для бота (Tonkeeper/MyTonWallet). Держите на нём сумму на 1–3 дня продаж. Сид-фраза хранится только в config.yaml на этом компьютере.
{{ 'Фраза уже задана — заполните поля, только если меняете кошелёк.' if secret('ton','mnemonic') else 'Tonkeeper → Настройки → Резервная копия. Можно вставить всю фразу в первое поле — слова разложатся сами.' }}
Адрес можно не вводить: бот сам найдёт кошелёк этой фразы (W5 или v4r2, формат 12 слов BIP39 или TON). Новый кошелёк без транзакций тоже подойдёт — бот развернёт его первой оплатой.

Шаг 3 · Fragment

На fragment.com войдите через Telegram, подключите этот же кошелёк бота (TON Connect) и пройдите KYC — без него Fragment не продаёт звёзды. Затем F12 → Application → Cookies → https://fragment.com → скопируйте stel_ssid, stel_dt, stel_token, stel_ton_token в виде stel_ssid=…; stel_dt=…; stel_token=…; stel_ton_token=…. Сессия живёт неделями; когда истечёт, бот скроет лоты и пришлёт уведомление.

Шаг 4 · Уведомления в Telegram (рекомендуется)

Нужен отдельный бот, не тот, что у MannBot: два процесса не могут читать команды одного Telegram-бота. Сначала напишите своему боту /start.
