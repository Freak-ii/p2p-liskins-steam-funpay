# Свой VPN для DPB Fastchange

Как это устроено:

1. Вы арендуете VPS за границей (основной — Амстердам, запасной — Франкфурт или Хельсинки).
2. На сервере один раз запускается `install-3xui.sh`: ставит панель **3x-ui** (Xray), включает протокол
   **VLESS Reality** на порту 443 (трафик выглядит как обычный HTTPS к www.microsoft.com — его труднее
   заблокировать), включает ссылки подписки для Happ, BBR и файрвол. В конце печатает блок настроек.
3. Блок вставляется в `config.yaml` ShopBot → `services.panels` (по блоку на сервер).
4. Покупатель оплачивает VPN в боте → бот через API панели создаёт клиента **на всех серверах сразу** (один UUID,
   срок = оплаченные месяцы, до 3 устройств) и присылает ссылку подписки + ключи `vless://` с инструкцией Happ.
5. Срок кончился — панель сама выключает ключ. За 3 дня бот напоминает; «Продлить» сдвигает срок того же
   ключа, в Happ ничего менять не нужно.

## Запуск (с компьютера на Windows)

```
scp "%USERPROFILE%\OneDrive\Documents\StarsCenter\vpn\install-3xui.sh" root@IP_СЕРВЕРА:/root/
ssh root@IP_СЕРВЕРА "bash /root/install-3xui.sh nl1"
```

Для второго сервера — то же с его IP и именем `de1` (или `fi1`). Пароль root вводите сами, когда спросит ssh.
Скрипт можно запускать повторно — он просто снова напечатает настройки.

## Нагрузка

1 ядро / 2 ГБ / 1 Гбит/с держит ~100 активных ключей (в пик онлайн 20–30 %, по 5–10 Мбит/с).
Второй сервер — когда ключей больше ~80 или вечерняя загрузка канала выше 60 %.
